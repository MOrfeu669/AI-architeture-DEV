# Find skill

1. Receba o link do repositório da skill ou do MCP.
2. Leia o repositório e descreva o que a skill faz e quando dispara.
3. Instale no projeto somente se a tarefa atual depender dela.
4. Não adicione skill extra. Cada skill a mais entra no contexto.
