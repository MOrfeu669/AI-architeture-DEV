# backend/api

Endpoints desta pasta.

- Invoque a skill `api` ao criar ou alterar rota.
- Cliente HTTP representativo: Lever. Consulte a doc atual via Context7 antes de usar nome de função ou classe.
- Um arquivo por recurso. O health check de exemplo fica em `backend/src/health.ts` e não é uma rota nova.
- Resposta de erro traz código e mensagem. Sem stack para o cliente.
